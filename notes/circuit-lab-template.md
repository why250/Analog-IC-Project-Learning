# 模块电路实验记录模板

复制本模板建立一份日期与模块命名的记录；待填项不得改成“通过”。

- 日期 / 课次 / 单一工程问题：待填写
- 学员预测与理由：待填写（采用助教假设时注明）
- library/cell/view / TB / DUT 实例：待填写
- TB 的单一作用、激励路径与观察路径：待填写
- 结构与关键节点 / 分相导通关系：待填写
- 模型边界：晶体管、行为、寄生及新网表绑定待填写
- 原包相对路径 / SHA-256：待填写
- 恢复副本、实验副本、改动与恢复步骤：待填写
- 工具版本、bridge profile、目标会话身份：待填写
- 保存配置 / 当前变量 / 模型 section / 温度：待填写
- 分析、初态、窗口、保存信号与采样方法：待填写
- 指标定义、单位、有效决定/有效码的取样相位、分析假设：待填写
- 预测值与推导条件：待填写
- 新运行 ID / history / 网表哈希 / 结果路径：尚未运行
- 仿真器完成状态 / 输出测量状态 / 电路验收状态：分别待填写
- 实测值与对应波形：待填写
- 图上事件 → 电路机制 → 设计判断；替代解释与受控对照：待填写
- 与预测差异及下一项定位实验：待填写
- 设计判断、收益/代价、系统适用范围：待填写
- 学员学习状态：待验证
- 下一项具体操作：待填写
