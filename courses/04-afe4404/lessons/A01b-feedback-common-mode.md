# A01b：TIA 外部反馈、共模感知与内部电容

本课问题：图中的反馈网络分别约束什么量，为什么改变一个电容不能同时保证增益、稳定性和建立？已确认结构，工作点、环路方向和性能待验证。原图：[AMP_6](../../../notes/evidence/afe4404/AMP_6.png)、[RC_CELL_2](../../../notes/evidence/afe4404/RC_CELL_2.png)、[CAP_SWITCH_5](../../../notes/evidence/afe4404/CAP_SWITCH_5.png)。

## 预测与三类网络

先预测增大外部 Cf、增大内部补偿电容、改变共模控制，各自首先影响哪个节点或传递量。区分 `vd=VOP−VOM` 与 `vcm=(VOP+VOM)/2`，随后核对真实连接。

| 网络 | 已确认结构 | 需要验证的功能 |
| --- | --- | --- |
| 外部跨阻反馈 | MI336 从 VOP/net713 返回 VM/net708；MI337 从 VOM/net714 返回 VP/net707 | 差分反馈方向、两侧等效 Rf/Cf、输入虚短误差 |
| 输出共模感知 | R18763/R18762 从 VOP/VOM 接公共 net119；C25221/C25220 也连接输出与 net119 | 共模提取、控制路径与环路稳定性 |
| 内部电容网络 | C18745/C18737 分别接 VOP→net103、VOM→net101；另有 ADJ 控制的电容支路 | 节点耦合、极零点、配置与实际补偿用途 |

共模感知节点和差分跨阻反馈在图上都“返回放大器”，但控制对象不同。整个差分环路稳定不代表共模环路稳定；也不能把 RC_CELL_2 的 Cf 当作全部内部补偿。

## 可配置外部反馈

RC_CELL_2 内 MI334/RES_ADJ_3 与 MI316/CAP_SWITCH_5 跨同一 PLUS/MINUS；两侧顶层实例使用相同控制 nets。几何对称与共用控制不保证实际 R/C 匹配或开关寄生完全相同。

CAP_SWITCH_5 的部分电容直接跨反馈端，其余经 MOS 接入。先由 gate 控制建立配置表，再写 `Zf(s)=Rf/(1+sRfCf)`；这个式子假设配置固定、开关可用线性 Ron 表示、R/C 已正确识别。若 gate 周期性切换，需时变电荷分析，不能继续用同一静态 Zf。

Rf 增大通常提高理想低频跨阻，但剩余 DC 同样被放大。Cf 增大通常限制高频反馈阻抗并改变噪声增益，也延长某些建立过程。加入输入总电容 Cin 时，一个单端等效半电路可用 `NG(s)=1+Zf(s)·sCin` 观察电压噪声到输出的放大；Cin 包括 photodiode、输入 MOS、互连和开关寄生，具体差分系数须按实际两端源模型确定。

OTA 开环极点、RfCf、Cin 和输出负载共同决定闭环，不能仅以 `τ=RfCf` 验收相位裕度。Cf 的选择要满足目标相位与有限窗口误差，产品推荐时间常数不能代替误差预算。更改合法配置时先查开关的电压范围、导通与过渡态，避免瞬间断开反馈。

## net119 能说明什么

如果两只输出感知电阻等值、net119 的负载可忽略，其 DC 值接近输出平均值。差分扰动的两项在对称条件下抵消，共模扰动同向相加。电阻不等、负载电流、控制钳位与频率相关电容会破坏这个理想平均。

本轮读到 P15669.G=net119，P15670.G=P14069_D，两者 D 均接 net60；source 分别是 P15669_S 和 net59，不能直接假定为普通共源差分对。P15669_S 又连 N15945/N15944、N15943/N15942 的 gate，并通向其他 bias 支路。由此可确认共模信息进入控制网络；完整反馈符号、目标值与带宽需要继续逐支路证明。

N15775 连接 net119→GS，N15776 连接 P15669_S→GS，gate 均为 X22095_ZN。共模节点存在受控钳位，启动/停机时的状态不能用正常线性环路推导。P14069_D 是实际参考节点名，其电压值尚未实测。

## 内部电容与输出级

输出 VOP 的下拉 N15860.G=net89，上拉 P15386.G=net92；VOM 对应 net87/net98。可见驱动由多个内部节点决定。连接输出与内部节点的电容可能形成补偿路径，也可能产生前馈和零点；仅凭跨级连接不能准确命名 pole-splitting 或给出零点位置。

ADJ2_* 控制的 MOS 连接输出与多组电容节点。要同时记录电容两端、开关两端、gate net 与 body；保存的尺寸/c/m 需要模型/CDF 语义才能变为总电容。图中两只电容的面积比例也不能直接变为完整配置码的带宽比例。

## 最小实验与验收

先交付三类反馈的节点表。模型就绪后，第一实验只验证共模感知：保持差分输入不变，给输出施加小的同向扰动，在适当的闭环 TB 中观察 net119 与控制支路。差模扰动留另一轮，检查共模泄漏。

分析环路时保持 DC bias 和所有必要负载；差分环、共模环与局部环的断点分别记录，不能将一个 loop gain 覆盖全部环路。若改 Cf，记录修改前后实际配置、工作点、负载和允许的采样误差，再测一种性能。

本课验收是能解释“哪个网络感知差模，哪个网络感知共模，哪个内部节点仍待验证”。随后回 [A01](A01-tia.md) 做跨阻/建立实验，或进入 [A02a](A02a-current-dac-structure.md) 阅读输入 DAC。
