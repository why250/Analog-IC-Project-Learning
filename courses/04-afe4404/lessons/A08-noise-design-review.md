# A08：输入折算噪声、相位相减与一次设计变更

状态：课文与方案已准备；无本工程噪声、失配、系统指标或前后比较实测。本课以前序已确认的模块与时序为条件，不把理想实验当成晶体管性能。

## 问题与预测

LED-on code 减 ambient code，噪声会下降还是增加？先明确噪声是否相关、各相位增益与 offset 是否相同，再选择一项你预测能改善输入折算 SNR 的电路变更。

## 预算口径

对两个随机样本 X/Y，`var(X−Y)=var(X)+var(Y)−2cov(X,Y)`。相等独立噪声相减后 RMS 增为 √2 倍；共同背景若高度相关可以被抑制。环境 DC 被去掉不等于独立器件噪声也被去掉。

跨相时间差决定相关性，也决定运动、光照变化和 LED 漂移会留下多少残差。若 Rf 或 offset 不同，原始码直接相减不一定得到光电流差，先转换到统一量纲并核对该模式产品定义。

只在测量频段内增益近似平坦时，可用 `iin,rms≈vout,rms/(2Rf)` 作输入折算；宽带情况下需要实际频率响应，不能用单一 DC 跨阻除掉所有噪声。TIA OTA、feedback resistor、offset DAC、switched sampling、buffer/ADC 及 reference 都应列入候选预算。

理想单个采样电容 kT/C 是特定网络平衡下的量级，不代表四相系统总噪声。对 clocked filter、DAC 切换、ADC，分析可能是周期时变的；普通小信号 noise 与 transient noise 的适用性需按实际电路和本机仿真器文档确认。

读出位数、mean averaging 次数和数据手册的 dynamic range 都不足以单独证明 ENOB。采样率、带宽、信号幅度、滤波、有效样本数和相关性必须一起报告。

## 最小实验与设计变更

先选一种噪声机制：例如固定输入下一个 held sample 的随机方差。固定供电、temperature、phase、bandwidth、采样窗及 load，记录噪声分析方式和随机 seed。五个确定性周期不是五次随机试验；统计采样数和置信范围在运行前约定。

确认主导机制后，只改一项，例如 Cf、sampling capacitor 或一个 bias。副本 A/B 使用相同输入、模型、测量时刻与指标。记录期望收益及至少一个代价：时间、功耗、headroom、memory 或 phase crosstalk。

最小回归包括来源 hash、真实模型/新网表、工作点、信号建立、输出有效相位、方向/符号码和约定噪声指标。仅噪声下降但采样残差恶化，不能称整体改善。

## 验收

交付“假设 → 单变量干预 → 新证据 → 判断”，解释收益与代价，保留失败点及恢复路径。若模型仍不齐，可完成预算和分析适用性审计，把实验标为未执行。

下一项具体操作由证据决定：选一个已定位模块的一项参数变更，不同时展开全 PVT、版图和全芯片。结课要求至少一次可复现的真实模块或系统 A/B 比较，以及学员独立的设计判断。
