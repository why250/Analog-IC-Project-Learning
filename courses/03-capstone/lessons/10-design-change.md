# 第 10 课：完成一次有证据的设计变更

**工程问题：** 怎样证明一个改动带来了收益，代价和适用范围又是什么？建议四次研修会话，仿真计算另计。

选择 ADC 或 PLL 中一个已定位的机制。前置：[ADC 回归评审](../../01-cadence-verification/lessons/06-regression-plan.md) 或 [PLL 噪声与锁定评审](../../02-pll-verification/lessons/09-noise-spurs.md)。记录：[综合练习](../../../notes/10-design-change.md)，执行遵守 [实验规范](../../../docs/experiment-protocol.md)。状态：方案待学员提出与实验验证。

## 1. 定义一个可证伪的改动

从现有证据选一个瓶颈：例如 CDAC 有限时间残差、比较器小过驱动判决裕量、PLL 校准/锁定时间或已建模的 spur。先提交一句话假设、当前值/预算、目标改善、代价和反证条件。

| 候选改动 | 必须先有的证据 | 关键代价/伴随验证 |
| --- | --- | --- |
| ADC 电容/桥接或采样窗口 | 实际权重与动态残差的区分 | 输入负载、能耗、速度、失配 |
| ADC 比较器尺寸或时序 | 固定共模、过驱动和初态的判决证据 | 功耗、kickback、输入电容、失调 |
| PLL CP/filter 参数 | 环路与启动机制、spur/噪声来源 | 锁定、稳定性、控制范围与噪声通路 |
| PLL 分数/校准控制 | 实际程序/状态序列和输出响应 | 通道精度、模式恢复、模型边界 |

范围只选一个主要机制。若需要同时改变多项，分阶段建立因果链，避免一次结果无法归因。

## 2. 冻结基线和比较方法

保存 baseline 的库/层级、config/ADE 设置、网表、外部模型身份和测量版本；复制需要修改的完整引用链，确认变更不会改变原基线 master。

明确前后固定的条件：输入/载频、供电、温度、模型绑定、初态、时间窗、解码/频谱定义、随机种子策略。若改动改变合法工作范围，分别给同条件比较和新范围验证，不把二者混为收益。

在实验前确定主要指标、最低改善和不可退化约束。改善小于数值/统计不确定性时，不宣布胜出。配对 Monte Carlo/噪声样本可减少差值方差，但样本定义和误差区间仍需说明。

## 3. 四次会话的产出

1. **方案评审：** 工作点/机制证据、预测、参数可编辑性、恢复路径与最小回归集合。
2. **局部验证：** 修改副本，核对网表 diff，做模块或短系统实验，确认干预确实进入运行。
3. **系统与边界回归：** 相同条件下比较关键系统指标，再选一个受牵连风险最大的边界；失败保留精确 run。
4. **复盘与交付：** 报告收益、代价、置信范围、未覆盖项、恢复方法和下一次选择。

## 4. 证据表和失败处理

| 项目 | Before | After | 差值/不确定性 | 判据 | 运行证据 |
| --- | --- | --- | --- | --- | --- |
| 主要目标 | 待实测 | 待实测 | 待计算 | 提前约定 | run ID/路径 |
| 速度/锁定 | 待实测 | 待实测 | 待计算 | 约束来源 | run ID/路径 |
| 功耗/面积代理 | 待核实 | 待核实 | 模型范围 | 预算来源 | 数据/估算方法 |
| 随机/边界性能 | 待实测 | 待实测 | 区间/条件 | 风险对应判据 | run ID/路径 |

功耗若模型无真实供电电流只能记缺失或有来源的估算；面积若只有器件总尺寸不能写成已完成版图面积。改动未改善也是有效课程结果，前提是证据有效且能够排除原假设或提出竞争机制。

## 5. 最终交付与结课验收

交付一份 2–4 页等量内容的 Markdown 工程评审，附小型证据索引、变更清单和再运行步骤；OA 与大波形继续留在服务器。文字应让未参与会话的工程师能判断配置、结果与模型边界。

结课验收要求：一条可追溯的设计问题—预测—干预—证据—判断链；至少一个实际系统比较；不可退化项和模型缺口清晰；学员能解释为何保留、修改或放弃这个设计改动。并非必须证明方案更好，但必须证明结论可信。
