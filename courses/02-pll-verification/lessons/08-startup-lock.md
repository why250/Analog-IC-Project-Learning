# 第 08 课：建立 PLL 启动、锁定与重调谐基线

**工程问题：** 波形看似稳定，是否真的锁在目标频率？建议两至三次 60–90 分钟研修。

前置：[第 07 课](07-spec-model-map.md) 的需求、配置与模型地图。记录：[第 08 课](../../../notes/08-startup-lock.md)。按 [实验规范](../../../docs/experiment-protocol.md) 执行。状态：无当前机器 PLL 仿真证据。

## 1. 预测与计时约定

先预测三种情况：不同初始 Vctrl、相同通道但不同启动顺序、整数模式转到分数模式。锁定时间、稳态平均频率和相位误差会怎样变化？哪些现象可能只是校准时间或编程延迟？

根据原规格确定计时起点，是上电、reset 释放、有效通道字写入还是校准完成。可分别报告这些阶段耗时，但不能将最有利的起点称为同一个“锁定时间”。

## 2. 入口与短试跑

候选配对为 `zambezi45_sim/pll_sim/config_powerup1` 与 `ams_powerup1`，以及 `config_plllock_TR` 与 `ams_plllock_TR`；只在第 07 课确认原状态用途及当前工具支持后选用。不能从名称推断仿真器已兼容。

先建立恢复副本和新 config 身份，核对供电、参考、reset、程序字、校准初态、实际模型绑定和 connect rules。短运行先回答数字编译是否通过、配置是否生效、VCO/反馈是否活动；再延长到能观察完整锁定。

## 3. 定义锁定测量

以实际节点和边沿阈值提取参考、反馈及指定输出的事件。定义频率估计窗口，例如跨 `M` 个周期测 `f̂=M/(t[k+M]−t[k])`，声明 `M` 和更新步长；单周期误差可能只是 DSM 引起的周期调制。

| 判据 | 定义与限制 |
| --- | --- |
| 平均频率误差 | `|f̂out−ftarget|/ftarget` 小于规格阈值，目标包含实际输出分频 |
| 相位行为 | 允许静态偏置和分数模式确定性调制；检查相位残差有界且不持续漂移 |
| 保持条件 | 连续满足判据达到预定 `Thold`，防止短暂穿过阈值假锁 |
| 控制与状态 | Vctrl 不被持续钳在边界，校准/锁定指示与模拟测量一致 |
| 重调谐 | 命令生效到新目标稳定的时间，期间掉锁/错误状态的恢复 |

阈值和保持窗口先从规格提取；没有规定时，声明课程判据及选择依据。时间窗越长，频率估计越平滑，但会掩盖瞬时失锁并增加报告延迟。

边沿相位的 modulo 值有界不能证明锁定。用累计边沿计数或解包裹相位检查 cycle slip 和长期频差。分数分频中，不应要求每个反馈周期都与参考精确等长；应核对平均关系和允许的调制。

## 4. 用模型解释瞬态而非只看 lock flag

小信号参考：若 `Kφ` 为 CP/PFD 增益 A/rad、`F(s)` 为 loop filter transimpedance V/A、`Kv` 为 rad/s/V，则 `L(s)=Kφ F(s) Kv/(sN)`。带宽与阻尼可解释局部小扰动趋势，不能直接代替大范围启动、饱和或校准状态机。

观察参考/反馈边沿、PFD 的 UP/DN、CP 电流、Vctrl、输出频率和程序状态。先从当前网表确定实际保存名。如果 lock flag 已高但 Vctrl 饱和、边沿计数持续漂移或输出分频错误，仍未满足锁定判据。

## 5. 一个基线和两个受控变化

1. 选规格中的一个 nominal 通道，完成新运行；记录程序字、目标推导、配置/编译身份与完整启动时间线。
2. 只改变 Vctrl/初态或启动顺序中的一个因素，保留其他条件；先从模型查合法设置方法，不能假定初始电压一定可编辑。
3. 在 nominal 锁定后做一次受支持的重调谐；记录命令发生、实际生效、校准和重新满足判据的时刻。
4. 检查日志、reset 和配置有效性，再解释锁定失败；避免把缺 connect module 或程序字未写入当成环路不稳定。

若计算成本过高，先用已校准的行为配置研究启动机制，再选一条关键非理想路径升级模型；同时保留“该层模型不支持实际噪声/功耗”的结论边界。

## 6. 验收与复盘

交付目标频率推导、启动时间线、输出/反馈平均频率、相位漂移检查、锁定区间和至少一个反例或受控变化。至少两种观察量支持锁定，不能只有 flag 或 Vctrl 曲线。

验收：测量定义可重现；目标包括输出路径；基线在明确条件下满足判据或给出可定位失败；初态/重调谐变化的结果能用当前模型解释。记录启动模型尚未覆盖的实际上电/电源域行为。
