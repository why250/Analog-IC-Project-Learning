# 第 09 课：审计 PLL phase noise、fractional spur 与 jitter

**工程问题：** 频谱中的底噪和离散峰来自物理机制、确定性调制还是观察窗口？建议三次 60–90 分钟研修，先做确定性 spur，再处理随机噪声。

前置：[第 08 课](08-startup-lock.md) 的稳态区间与有效输出节点。记录：[第 09 课](../../../notes/09-noise-spurs.md)。按 [实验规范](../../../docs/experiment-protocol.md) 执行。状态：分析方案待对应当前模型验证。

## 1. 预测

关闭随机噪声的 fractional-N 行为仿真中，是否仍能出现 spur？记录长度翻倍、打开 DSM dither 或改变 CP mismatch，哪些峰应改变位置、哪些改变幅度、哪些只改善分辨率？先写机制预测再选择实验。

## 2. 先审计噪声是否真的存在

选择课 07 已核实、课 08 已跑通的配置；不假定工程存在名为“phase_noise”的 test。记录 VCO、参考、CP/PFD、divider、DSM 和 connect module 包含哪些非理想因素：随机噪声源、失配、死区、有限边沿、量化、dither、供电耦合和饱和。

无噪声理想 VCO/门不能给出真实器件 phase noise。即使有 transistor VCO，其他理想模块仍可能漏掉重要噪声/杂散通路。行为噪声模型的强度、频率形状和带宽需对应来源或校准数据，不能只凭“包含 noise()”就认定正确。

## 3. 选择与模型一致的分析方法

| 方法 | 适用前提 | 要核对的限制 |
| --- | --- | --- |
| 稳态时域频谱/相位记录 | 有足够长、已锁定的输出数据 | 时间步、边沿阈值、窗口与频谱标定 |
| 含随机噪声的时域记录 | 确实打开并正确建模动态噪声 | 种子、噪声带宽、估计方差与记录长度 |
| 周期稳态与小信号噪声 | 当前电路/绑定支持相关分析，周期定义正确 | 周期长度、sideband、收敛及采样/输出口径 |
| 模块噪声与环路传递拼接 | 模块工作点与环路增益已核对 | 非线性、相关性与模型校准 |

fractional divider、DSM 和 dither 可能使环路缺乏简单短周期；合理分数频率的存在不保证 DSM 状态序列具有短周期。先检查实际序列，不能直接用 `1/fref` 当整个系统的 PSS 周期，也不能未经当前工具文档就自动套某个多音稳态分析。

若完整环路不适合周期小信号方法，用已验证时域记录研究确定性 spur，模块层研究器件噪声，再明确系统拼接边界。模型能力缺失时，可完成机制和测量方案的课程验收，产品指标仍记未验证。

## 4. 频谱与相位记录的口径

稳态有效记录长度 `Tobs` 给出约 `1/Tobs` 的 Fourier bin 间隔；零填充不会提供同等物理分辨率。减小时间步不等于延长低 offset 观察时间，输出数据抽取必须有防 alias 或经验证的相位采样方法。

若从边沿提取相位，说明阈值、极性、插值精度、理想时间栅格与输出载频。移除确定性频差/趋势的方式要固定；过度去趋势会删掉真实低频噪声。周期 jitter、period-to-period jitter、TIE 与积分相位 jitter 分别定义，不混用 RMS 值。

单边带 phase noise `L(f)` 单位 dBc/Hz，离散 spur 通常为 dBc。按每 bin 功率与噪声密度的关系处理 ENBW，不能将一个尖峰除以 bin 宽度后当成随机底噪比较。

在小相位近似、`L(f)` 为对应载频单边带密度的条件下，随机积分 jitter 为：

`σt = sqrt(2 ∫[fL,fH] 10^(L(f)/10) df) / (2π fc)`。

说明积分 offset 范围、载频 `fc`、两侧因子与是否剔除离散 spur；如需包括确定性 spur，另按明确口径加入其相位功率，避免重复积分。相同 PLL 在不同输出分频端口的 phase noise 数值与载频会变，不能只比较 dBc/Hz 就判 jitter 改善。

## 5. 三个有区分力的实验

1. **窗口对照：** 在相同已锁定配置下增加观察长度，比较峰的位置、归一化幅度和底噪估计；先排除 carrier leakage 和 bin/窗标定。
2. **整数/分数机制对照：** 使用受支持的整数和分数设置，核对实际 divider/DSM 序列。优先选择平均载频可比的条件；若不同，记录 VCO 工作点和环路变化，不能把全部差异归于 DSM。
3. **单一非理想干预：** 选择 CP mismatch、PFD dead zone、VCO noise 或 dither 中一个实际可控参数，预测 spur/噪声趋势，保留其他条件和统一测量。

这三项可分会话完成。先完成确定性 spur 的最小对照，再投入随机噪声样本；每个运行固定其精确 history/输出目录，不混用“最新结果”。

## 6. 验收与 PLL 单元评审

交付一个 spur 机制对照和一份 phase noise/jitter 测量预算：包括信号端口、载频、offset 范围、窗与 ENBW、记录长度、噪声模型、误差范围和实际结果状态。

验收：能区分 spur 与密度，控制记录长度和归一化影响，给出一项受控机制的证据，并说明哪些物理指标尚未覆盖。若只有行为模型功能结果，不把它升级为真实 PLL 噪声签字。

**设计判断：** 提高带宽可能减小 VCO 某 offset 的贡献，同时增大参考/量化通路的贡献。结合课 08 的锁定成本和当前噪声来源，提出一个有明确验证路径的改动，进入综合练习。
