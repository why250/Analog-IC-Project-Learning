# S02：split CDAC 的桥接电容为什么接近一个 Cu？

问题：两组各 5 bit 的电容怎样组合成 10 bit 位权？先预测：桥接电容增大后，LSB 组相对 MSB 组的权重增大还是减小？最大的线性误差更可能出现在哪类进位边界？

## 从本工程重建阵列

当前 core 使用 `gpdk045/mimcap`。保存的 unit 参数为 `c=15.2265f`，桥接 `C54/C55` 保存 `c=15.724f`，分别连接 `sump↔net9`、`sumn↔net8`。每组可读到 1、2、4、8、16 个 unit 的实例数组，另有低位侧 dummy。数组总电容要同时核对实例数量、`m` 和新网表展开，不能只读单实例的 `c`。

独立 TB `saradc/10Bit_capdac_TB_new` 用的是 `saradcII/10BIT_CAPDAC_ld1`，并非当前 core 的一个直接子实例。两者都为 split 阵列，但采样 mux 的版本不同。独立 TB 可学习机理；用于系统结论前必须比较位权与动态连接。

## 两节点电荷守恒

令比较器侧为 x，低位内部节点为 y。高位阵列总和为 `CH`，低位总和含 dummy 为 `CL`，桥接为 `Cb`。忽略寄生，保持期间：

```text
(CH+Cb) ΔVx − Cb ΔVy = ΣH Ci ΔVbi
−Cb ΔVx + (CL+Cb) ΔVy = ΣL Cj ΔVbj
D = CH CL + Cb(CH+CL)
ΔVx = [(CL+Cb) ΣH Ci ΔVbi + Cb ΣL Cj ΔVbj] / D
```

相同一个 Cu、相同底板阶跃，高位和低位的贡献比为 `(CL+Cb)/Cb`。若低位组为 5 bit，要求高位 unit 是低位 unit 的 32 倍，就得到 `Cb=CL/31`。在 `CL=32Cu` 的理想阵列中，`Cb=32Cu/31`。本工程保存比值约 1.0327，与理想 1.03226 接近；这只是保存值与简化推导的比较，不是已测匹配或提取结果。

低位 y 的对地寄生进入 `CL`，直接改变衰减；x 的对地寄生进入 `CH`，改变整体增益。桥接本身的寄生耦合还可能不能归为简单对地电容。必须在定义清楚 top/bottom plate 和 reference 轨迹后区分 gain error、位权比例误差和 code dependent error。

当 `Cb` 增大，低位贡献相对高位增大。进位时低位组复位、高位 unit 置位，二者不再恰好互补，因而组间进位是灵敏观察点。误差符号仍取决于差分两边 reference 接法。

## 开关、参考与动态建立

底板 reference mux 由 NMOS/PMOS 与数字门构成。开关宽度随负载变化，但宽度增大同时增加 driver 负载与 charge injection。参考端的电流脉冲由切换电容、共模轨迹及切换策略决定，不能用 `C V²` 一个式子替代完整能量审计。

理想一阶残差 `e(t)=e0 exp(−t/τ)`。若全幅阶跃允许 `0.5 LSB`，10 bit 下需 `t/τ > ln(2048)≈7.62`。实际各位阶跃不同、reference buffer 和 mux 可能非线性，应按位记录残差与剩余建立时间。

## 最小实验与验收

第一项只测位权：固定采样初态与参考，逐位单独切换，记录充分建立后的 `Δ(sump−sumn)`，归一化到最低位。用联立方程预测，再核对顺序。现有 TB 的行为 ADC 给码方式未必支持这个干预，应在工作副本建立受控数字源。

第二项在副本中将桥接电容改变 ±1%，其他保持不变，测组间进位附近的阶跃与静态位权；第三项才缩短建立窗口。别把动态未建立当作静态 mismatch。验收要提交实际展开电容表、十个位权、进位误差方向及系统适用范围。
