# 第 03 课：审计输出解码、采样窗口与动态指标

**工程问题：** 漂亮的 ENOB 来自电路性能，还是解码、截取和 FFT 定义？建议两次 60–90 分钟研修。

前置：[第 02 课](02-nominal-baseline.md) 的有效转换与稳定码相位。记录：[第 03 课](../../../notes/03-dynamic-metrics.md)。执行遵守 [证据规范](../../../docs/experiment-protocol.md)。状态：待实验验证。

## 1. 预测

预测三个变化的影响：取码时间跨过输出更新边沿；将输入从相干频点偏离半个 bin；将输入幅度降低。哪些会改变电路行为，哪些只改变处理结果？预测后再进行下面的计算与实验。

## 2. 建立可核对的码序列

本课入口仍为 `saradc/10Bit_ADC_TB_new/maestro`。沿当前输出表达式核对从模拟位电压到码的阈值、bus 方向、位权、极性和编码。实际 schematic 中 DUT `out<9:0>` 接到顶层 `out<0:9>`；名称反向不自动证明错误，也不能默认下标就是数值位权。用网表、控制器输出赋值和低速/局部已知输入检查映射。

建立 `code = Σ b_j·2^j` 前，先确定每个物理输出对应哪个 `j`；二补码或其他编码另行处理。缺码、未知值、位过渡造成的短码不可简单删除后仍宣称等间隔采样。

从本次 history 抽取稳态等间隔样本。记录每个有效码读出时刻，并对应到该转换的输入 hold 时刻。若用输入与输出残差比较，必须补偿转换延迟；不能将锁存时刻的输入直接当作该码所代表的采样输入。

## 3. 核对刺激与幅度定义

当前保存配置为 `fsample=100M`、`numPoints=1024`、`tone=503`：推导 `fin=49.12109375 MHz`、bin 间隔 `97.65625 kHz`，503 与 1024 互质。以确实等间隔的 1024 个有效样本为前提，相干关系成立。

| 来源 | 已知表达式 / 本课核对 |
| --- | --- |
| Maestro | `vin=percentFullScale*fullInputScale=0.84*(VDD/2)=0.504 V` |
| 顶层 V6/V7 | 两个反相 vsin 的 `va=0.95*vin/2`，相位 0°/180° |
| 电路推导 | 单端峰值约 0.2394 V，差分峰值约 0.4788 V；不是直接把 `vin` 当实际差分幅度 |
| 源公共偏置 | 两个输入源的另一端接 `net22`，V5 保存 `0.8*VDD`；与 DUT 的 `vcm=0.5*VDD` 区分 |
| 参考与量程 | V12/V14 保存 `VDD` 与 `0.6*VDD`；从参考连接、CDAC 结构和传输曲线推导实际输入范围 |
| LSB | 文件 `quanta=VDD/2^numberofbits` 只是表达式；不能未经量程核对就当作实际 ADC 输入 LSB |

以上是文件/电路推导，需网表和波形确认输入幅度及共模。电压归一化若依赖错误 LSB，会使失真与幅度判断失真；码域 SNDR 的共同线性缩放则不会改变功率比。

## 4. 先定义功率集合，再算指标

对同一记录明确 DC、基波、谐波、其他 spur 和噪声的归属。实序列采用一侧频谱时，正频率内部 bin 的功率需正确翻倍，DC/Nyquist 不翻倍；窗函数的相干增益和 ENBW 分别影响幅度及噪声密度标定。用 Parseval 或已知正弦核对总功率，避免 FFT 长度归一化错误。

- `SNDR = 10 log10(Psignal/(Pharmonic+Pother_spur+Pnoise))`，剔除 DC 后，其余失真与噪声都进入分母。
- `SNR` 的分母是否剔除谐波和特定 spur，必须显式声明；不要通过移除非谐波 spur 人为提高它。
- `SFDR` 用基波与最大离散 spur 比较，写清谐波是否计入、dBc/dBFS 口径及 DC 处理。
- `ENOB=(SNDR−1.76)/6.02` 是常用满量程正弦参考换算。低于满量程输入时，直接换算值与按输入 backoff 外推的值分别报告，后者不是已测满量程性能。

相干、稳态、无随机扰动的记录可用矩形窗；非相干记录需选窗并为基波/谐波积分主瓣。基波和谐波的选 bin 宽度必须一致且互不误删。接近 Nyquist 时谐波会折叠，按 `r=(h·fin) mod fs`、`fh=min(r,fs−r)` 找位置；撞到 DC 或基波的分量无法仅凭单次频谱分离。

## 5. 一个交叉核验实验

1. 在基线副本恢复足够长的 transient。保存的 `TSTOP_tran=10.32 µs` 不自动保证启动后能拿到 1024 个有效码；由课 02 测得的稳态开始与取码相位决定 stop。
2. 对精确 history 取同一批 1024 个码。记录第一/末个样本时刻、样本间隔、解码规则和实际输入。
3. 审计现有 ADE 指标表达式，独立用 Python/MATLAB 或其他可核查算法对相同码序列计算，统一 DC、谐波、窗和单位。
4. 对同一运行数据，在稳定区内移动取码相位，看指标是否基本一致；再故意跨位更新边沿作为反例，标记此测量为无效。
5. 只做一次频点控制实验：保留电路条件，将输入偏离相干点，比较矩形窗与正确窗处理；不要与幅度、噪声开关同时改。

保存 `sample_index,time,code` 的小型 CSV、频谱摘要、指标表和处理脚本身份。已有 `SARADC_ENOB_calculation.xlsx` 是待审计的历史测量工具；若使用，须另查公式、窗、频点与导入列，不能当作正确算法的先验。

## 6. 验收与设计判断

验收：两种方法对同一数据和定义得到相容指标；差异若超过预先约定的容差（例如教学用 0.1 dB，需说明适用条件），能够定位至解码、积分集合、窗或归一化。能解释 `f_fftbin=fnyquist/128` 是否被使用及为何与 1024 点 bin 间隔不同；未使用也需有引用搜索/表达式证据。

漂亮频谱仍可能受理想控制、有限记录长度、输入共模、缺失噪声、模型切换和饱和限制。明确本次 SNDR 支持的输入条件与模型边界，然后用课 04 定位一个主导残差。
