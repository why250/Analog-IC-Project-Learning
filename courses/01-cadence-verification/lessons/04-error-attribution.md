# 第 04 课：从系统残差定位到采样、CDAC 与比较器

**工程问题：** 哪个非理想因素主导当前误差，怎样用最小干预证明？建议两至三次 60–90 分钟研修，每次只验证一个机制。

前置：[第 03 课](03-dynamic-metrics.md) 的可信码和动态指标。记录：[第 04 课](../../../notes/04-error-attribution.md)。按 [证据规范](../../../docs/experiment-protocol.md) 保留副本与基线。状态：待实验验证。

## 1. 预测：先提出误差指纹

选择当前最大的异常，预测其随输入频率、转换速率、码型或输入幅度如何变化。写出两个竞争机制和能区分它们的一次干预，避免见到谐波就认定电容失配。

| 现象 | 候选机制 | 可区分的观察 |
| --- | --- | --- |
| 随输入频率增大 | 采样建立、带宽、时钟抖动 | 采样结束的实际输入残差与相位 |
| 随转换速率增大 | CDAC 建立、比较器再生或控制相位 | DAC/比较器决策前的裕量 |
| 码型相关且低速仍在 | 权重、桥接电容、参考依赖 | 低速转移与关键进位残差 |
| 接近阈值随机错误 | 比较器噪声、失配或再生不足 | 相同初态的重复判决与延迟 |
| 大幅输入明显变坏 | 饱和、共模偏移、开关非线性 | 实际输入/参考和内部共模范围 |

这些是诊断方向，不能独立作为结论。

## 2. 从实际 master 选择模块实验

本包已核实的入口包括 `saradc/10Bit_capdac_TB_new/{schematic,maestro,maestro_mc}`、`clockPhaseGenerator_TB_new/{schematic,maestro}`、`clockPhaseGenerator_dc2dc_TB_new/{schematic,maestro}`、`comparator_offset_TB_new/{schematic,maestro}`、`comparator_tran_noise_TB/{schematic,maestro}`。

先确认这些 testbench 的 DUT master 是否对应系统中的实际模块。顶层 ADC 用 `saradcII/10bit_adc_core_w_split_dac_ld1_msb`，不能因为独立 TB 名称包含 capdac/comparator 就认定其结果可直接回灌。

## 3. 三个机制的参考判断

**采样与建立。** 单极点残差近似 `|e|=|ΔV|·exp(−t/τ)`。给定最坏输入变化与允许误差 `ε`，需要 `t≥τ ln(|ΔV|/ε)`；“约 (N+1)ln2 个时间常数”只在满量程阶跃、0.5 LSB 预算和相同范围定义下成立。本工程采样时间静态推导约 1.667 ns，实际可用窗口需扣除边沿和非重叠；也不能默认只存在一个极点。

**CDAC 权重与桥接。** 沿实际 split-DAC 拓扑写电荷守恒，包括桥接电容、上下阵列寄生、底板切换与参考端阻抗。先预测某个关键进位前后的差分步长，再在相同采样/切换条件下读稳态和有限时间残差。不能将电容面积或 `c` 参数直接等同最终权重，也不能把理想权重测量扩展为动态建立性能。

**比较器判决。** 在决策发生时记录输入差分、输入共模和可用再生时间。再生延迟随小过驱动增大可作候选解释；过驱动测试须覆盖正负极性并控制初态。噪声和失调在课 05 分开测，当前优先验证有限时间的 nominal 判决。

## 4. 最小因果实验

1. 选一个目标指标：如决策前差分残差、某次进位误差或小过驱动判决延迟；给定预算。
2. 用同一基线保存输入、内部关键节点、控制边沿和输出；确认当前误差确实可重现。
3. 只在副本改变一个因素。采样问题可先改变速率/采样窗口；DAC 问题可做低速建立对照；比较器问题可改变可用决策时间。具体可编辑变量先从实际电路查，不假定 `ron_sample` 一定被使用。
4. 若改变整个采样率，要同步保持内部周期关系和输入相干条件；该干预同时影响多个时间预算，只能得到“速度相关”的第一层结论，再用模块实验隔离。
5. 对模块 TB 复现系统的共模、参考、负载、控制相位与初始状态，解释不一致项。
6. 将改善机制回到系统中验证。模块结果改善而系统无改善时，检查瓶颈转移、绑定、负载和测量不确定性。

理想模型替换能给出某机制的可能上界，但同时可能改变负载、延迟和工作点。保留边界条件；只有替换差异受控且系统结果与机制预测相符，才形成因果证据。

### 静态线性：区分权重误差与动态建立

如果异常集中在关键进位，建立低速输入转移实验副本：固定初态和足够建立时间，单调扫实际差分输入；每个输入点等待有效转换。围绕码转移阈值细化输入步长或做局部搜索，不把输入源设置步长当作阈值测量精度。扫描应覆盖有效输入范围，注明端部码、迟滞、随机判决和未到达的阈值。

设第 k 个码的低端转移为 `T[k]`，码宽 `W[k]=T[k+1]−T[k]`。在已约定的有效码区间用 endpoint 或 best-fit 确定理想 LSB 和偏置，再定义 `DNL[k]=W[k]/LSBideal−1`；INL 用同一理想转移线的偏差除以 `LSBideal`。内部码和端部饱和码分开处理，报告口径；bus 位权、量程、offset/gain 尚未确定时，不直接计算并解释 INL。

在明确编码与理想 LSB 的条件下，缺码对应零码宽，单调性与码跳变还需独立检查。含噪声时阈值应按指定判决概率测，不能从一次往返翻转中得到精确静态线性。码密度法作为替代时，要审计输入概率分布、样本相关性、端点和统计区间。

最后比较低速静态转移与标称速率：若低速残差保留而动态残差增加，分别提出权重/参考与有限建立解释。不能用低速 INL 通过证明高速动态精度通过。

## 5. 输出与验收

交付一个两至三条件对照表：改了什么、哪些量固定、模块局部指标、系统指标、数值不确定性。至少一张图显示从控制变化到决策前的误差演变，并给出被排除的竞争解释。

验收要求：主导机制的方向预测与受控实验相符；模块 TB 与系统绑定/边界可比；若仍不能区分，则明确需要的下一次干预，不把弱相关写成已归因。

**设计判断：** 加大电容、放缓转换、增强比较器或调整采样窗口中，哪一项最值得做？用当前预算解释其功耗、速度或统计代价，再进入课 05 检验随机误差。
