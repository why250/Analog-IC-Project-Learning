问题：第二级量化的是原输入，还是第一级量化后的残差？预测：若级间增益有 1% 比例误差，误差会如何随第一级 code 和残差变化？本课使用 `Pipe_SAR` 的已有 bridge 导出；源资料 PPT 的性能值和结构解释均需实验核对，本工程尚未建立新前仿。

## 实际入口与信号链

OA 名称 `Pipe_SAR/Pi-SAR_amp/schematic` 的文件夹是 `Pi#2dSAR_amp`，不要把文件夹编码当作逻辑 cell 名。其保存状态有 spectre_state1/2，运行时需要查各 state 实际模型、变量和分析。

| 顶层实例 | Master | 连接给出的作用 |
| --- | --- | --- |
| I0 | `DYSAR6b_200M` | 六位 din<5:0> 输出；CAP_UP/CAP_DOWN 接 VPN/VNN，提供级间残差信号入口 |
| I3 | `amp_gainboost` | 输入接 net88/net86；VON/VOP 交叉接 VIN2+/VIN2−；受 CK1/CK2 控制 |
| I11 | `PiSAR_2st_8bit` | 输入 VIN2+/VIN2−，输出 D2<7:0>，SAM− 接 CK2 |
| I14 | `D_adjust2` | 两级码及 c1 进入，输出 D<11:0> |
| I82 | `DAC_VA12` | 将十二位结果按 CK 观察为 OUTA，属于行为测量路径 |

外围 TG 和电容把第一段残差采入 net88/net86，与放大器内部开关电容反馈共同决定传递。第一项阅读任务是分 CK1/CK2 建立连接表，确定采样、放大、第二级 acquisition 的有效窗口。VON/VOP 的交叉意味着测增益要明确差分符号，不能仅从 VOP 名字判断最终 VIN2+ 的方向。

## 残差模型与误差传播

用统一输入参考和极性定义 `r1=x−xq1(c1)`，级间输出 `y=G*r1+eamp`，第二级重构 `yq2`，则理想合成 `xhat=xq1(c1)+yq2/G`。符号、参考尺度、gain 和 digital latency 必须由实际连接及源码确定；这里是模型框架。

若实际 G 与数字合成使用的 G0 不同，输入参考的增益误差项约为 `(G/G0−1)*r1`，会与残差幅度和第一级码段关联。第二级量化/offset 的输入参考误差则约除以 G0；第一级 offset 是否能纠正，取决于残差仍处于第二级/冗余范围且合成正确，不能说它总是不影响精度。

PPT 提出名义级间增益 8；先按实际 sampling/feedback 电容、两相连接及负载重推，再扫小残差测闭环增益。六位和八位总码进入十二位输出，表面有两位重叠，但冗余边界与合成位权必须从 D_adjust2 的实际加法/延迟链查清；不能只做“6+8−2=12”便认定正确。

## 三类关键 TB 和结果分析

| 实验 | 激励与保存量 | 结果如何区分机制 |
| --- | --- | --- |
| 级间静态传递 | 固定两相，扫已知残差；看 VPN/VNN、输入采样节点、VIN2 差分与共模 | 长窗后仍有比例误差，检查 capacitor ratio/有限 DC gain；压缩/饱和需查 range/headroom |
| 放大器动态建立 | 固定残差阶跃，扫放大窗/负载；保存主输出、辅助节点与共模 | 短窗误差大、长窗改善提示 settling；slew、振铃、慢尾巴分别用电流与节点响应定位 |
| 数字合成/对齐 | 可识别的输入序列及受控两级码；保存 c1、din、D2、D 和 CK | 错一个采样周期会混合不同输入的 coarse/fine；在理想残差下先审计数字链 |

`amp_gainboost` 实际含 `ampGA`、`ampGB`、`Bias`、主 MOS、TG 和两相 SC 网络。gain boosting 改善静态增益，但主环路、辅助环路和共模路径的动态不能只用一个 GBW 判断。存在慢尾巴时保持输入/负载，改变辅助支路或观察其节点，以小步对照验证候选机制；稳定性检查的断环位置和方法先查工具文档，不破坏 DC 工作点。

先做名义值及少量偏移的残差传递，不直接扫全系统长 sine。确认传递符号与 range 后，让第一级 threshold/offset 偏移，观察第二级是否仍能接收残差，并检查重构连续性；冗余能力以这条实验链证明。超过第二级 range 的错误，不能靠数字对齐补回。

## 性能报告怎样核对

已有 PPT 文本在同页列 ENOB=11.6 bit 与 SNR=61.20 dB。若二者来自相同数据和标准定义，SINAD≤SNR，故 ENOB≤(61.20−1.76)/6.02≈9.87 bit。先核对图、测量幅度/窗口和标签来源，再决定是否是报告笔误或不同运行；不把 11.6 bit 当成本机实测。

最终系统运行在两级都正确的有效时序内逐次取 D<11:0>。同时保留一级残差、二级输入和两级码，以定位谱线或码段异常。行为理想 DAC、放大器模型和后仿寄生的精度分别标明；保留每个指标的输入参考定义。
