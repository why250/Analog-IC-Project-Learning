# 没有 testbench 时，怎样学习逆向电路

没有 TB 不妨碍读晶体管和反馈结构，但不能直接得出商业 ADC 的性能。先拆出一个边界闭合、假设可检验的小问题。对这两套工程，最大的准备工作是确认模型与控制协议，而不是先做整芯片 FFT。

## 三层实验

| 层次 | 做法 | 结果支持什么 |
| --- | --- | --- |
| 结构 | 原图 + OA 端子表；追输入、反馈、偏置、时钟 | 连线、镜像/电容接法、控制候选；工作区仍待确认 |
| 理想/近似教学模型 | 理想开关、电容、受控源、归一化状态；近似 MOS 必须注明来源 | 分相、极性、比例与误差趋势；不能代表芯片 noise/INL/速度 |
| 工艺器件模块 TB | 匹配 MOS/BJT/passive 模型、CDF、端口及环境；保留真实反馈与负载 | 指定模型和条件下的新测量；与产品一致性仍需验证 |

本次在两个项目目录递归检查 .scs/.sp/.spi/.cir/.va/.vams/.mdl/.lib 未找到候选文件，view 目录未发现 maestro/adexl/config/veriloga。DEV 的 spectre 等 view 指向 `symbol.oa`，说明有接口视图，尚未确认 CDF 的 simInfo、model name 和 include/section。这个结论仅覆盖这两个目录，模型可能在别处。

不要为了让网表“能跑”就把所有 `_H`、DNW、非对称 MOS 映射成同一种普通 MOS。器件阈值、隔离井、body connection、耐压与噪声机制会不同。若重建教学电路，建立自己的 library 和实例表，原库不改；记录每一项替换。

## 先填写模块接口合同

1. 实际 library/cell/view、上层实例与网名；区分外部产品引脚和逆向层级端口。
2. 电源域、各 ground/reference 地、输入共模、bias 是电压还是电流；NIB/PIB 名称不能代替端子追踪。
3. clock/control 的完整状态向量、有效极性、初态、非重叠和边沿；没有确认前不绑 0/1 常量。
4. reference 及源阻抗、外接去耦、代表性负载、相邻模块反馈；特别标出切走后会悬浮的节点。
5. 所有器件模型来源、仿真 view/termOrder、参数单位、m 与几何是否已重复计入。
6. 观察点、测量窗口、误差阈值来源、一个预期失败条件和恢复方法。

## 首批 TB 的用途与结果分析

| 候选 TB | 先回答的问题 | 刺激/保留条件 | 观察结果与反证 |
| --- | --- | --- | --- |
| ADS8681 BOOTSTRAP 升压驱动 | Z 如何超过供电？ | CLK、原 precharge 支路、代表性 gate/C 负载 | 看 C356 两端与 Z；不升压先查初态/时序，衰减查负载和泄漏；不能称为 input acquisition |
| ADS8681 CDAC 单次切换 | 位权与比较输入方向是什么？ | 固定输入、reference、一个确认的 switch vector，其余保持 | 比较长窗电荷步幅与短窗建立；恒定长窗误差查比例/寄生，随等待时间变小查建立 |
| ADS8681 COMP_2S2 | 动态判决与 Q/QS 锁存是否同一事件？ | 确认 CLK/CPN/SWN、bias、共模、上一周期结果 | 看耦合电容后输入、原始动态节点、Q/QS；交替差分排除旧结果保持 |
| ADS1248 PGA | 反馈选择是否改变差分增益？ | 两只 AMP、梯形电阻及开关、bias/CLK 和输出负载一起保留 | 中央线性段拟合 slope/intercept，再扫共模；饱和不归为 offset |
| ADS1248 单份 SWITCH_CAP | 两相产生多少差分电荷？ | 确认各 SW 极性、VI1…VI5、VO1/2 接收阻抗、GS | 理想开关下先验证电荷守恒；实 MOS 另分 injection、泄漏与 Ron 建立 |
| ADS1248 单级 AMP_9 | 是保持、积分还是复位？ | 同时保留 feedback C 与各相开关、输入参考、bias | 看每相端点和输出状态；不能凭一条阶跃波形认定积分器 |
| 两者 reference buffer | 采样负载怎样污染 reference？ | reference 反馈、去耦/ESR、受控电流脉冲负载 | 看 droop、恢复与振铃；扫去耦和脉冲面积区分输出阻抗与环路问题 |

第一轮只做 DC 工作点或几个周期的 transient。出现正确方向和工作区之后再测 settling；结构/极性都未闭合时不要跑 noise 或 Monte Carlo。动态 SC 电路的平均工作状态与噪声折叠需要周期分析或合适的 transient-noise 方法，静态 AC/noise 不自动等于运行中的输入参考噪声。

## 一个无需器件模型的起步实验

在 [D03](ads1248/D03-switched-cap.md) 推导理想 charge transfer：若采样电容 Cs 的差分电压改变 Δv，接收电容 Cf 上的差分增量为 `s·Cs/Cf·Δv`；符号 s 由真实端子和分相决定。先手算单次，再让理想模型复现。另做“延长相位、增加寄生、改变 Cs/Cf”三组对照，各次只改变一个因素。

这个实验没有指定真实 Cs/Cf 和 CLK 频率，也没有使用商业 ADC 模型。它能把读图变成可证伪的电荷判断。若手算与理想实验不一致，先修正拓扑/符号；不通过调 MOS 模型掩盖问题。

## 推荐顺序

ADS8681 先读升压→前端反馈→CDAC/比较器→reference；ADS1248 先读 PGA 反馈→SC 单相→多级量化/反馈→低频误差。每课完成一张自己的分相/反馈图和一份误差预算即可推进，随后在可运行的已有 SAR 工程做相同机制的真实实验，再返回逆向模块恢复模型。

整芯片 SAR 输出码、ΔΣ bitstream 和最终滤波码是三个不同观察层次。缺少配置协议或数字滤波时，用显式的行为源代替边界并注明；不能把教学滤波器输出标成 ADS1248 实测码。
