# D06：低频精度与没有滤波器的系统实验

问题：观察调制 bitstream 能否直接报告 ADS1248 的 24 bit 有效精度？先预测：改变输出滤波带宽，即使电路不变，RMS 码噪声是否会改变？本课准备结果分析合同。

先分三个观察层次：晶体管/SC 的相末状态、量化器 Q 的 bitstream、数字 decimation 后的输出码。本次只检查了部分模拟层级和 Q→CLK_CTRL 的边，未闭合完整数字滤波/输出协议。需要行为滤波时自行定义系数、抽取率和单位，标成教学滤波，不称产品真实滤波器。

| 实验 | 设置与分析 | 可以支持的判断 |
| --- | --- | --- |
| PGA DC 增益/offset | 固定 gain/common-mode，中央区拟合；温度为另一次实验 | 给定模型/条件下的 slope、截距与输入范围 |
| 输入短路 noise | 指明短接共模、gain、clock、滤波、带宽、长度和启动丢弃区 | 指定输出定义下 RMS；无有效 noise 模型不做定量结论 |
| 小 DC bitstream | 先确认状态有界，再看平均、周期模式与长记录 | 反馈方向、idle tone 候选；不是有效位数证明 |
| 输入/增益切换 | 保留前一输入状态，记录到达误差带的时间 | 模拟建立与滤波 memory 的分离 |
| 50/60 Hz 干扰 | 指定采样率、教学/真实滤波器和信号相位 | 本定义下抑制比，不能冒充 datasheet notch 模式 |
| 过载与恢复 | 明确过载幅度、长度和回归小信号时刻 | 状态饱和/恢复，而非稳态 linearity |

结果定义：输入参考 RMS=`σout/|G|` 只在输出到输入的量纲/增益闭合时成立；ENOB、noise-free bits 和峰峰值不是同一个量。峰峰值依赖记录长度及分布，不能固定用任意倍数 σ 当作实测。低频 noise 包含 1/f、reference、bias、源阻抗热噪声和周期切换折叠，各项需带宽和传递函数。

行为阶段先运行由 D03/D04 方程得到的归一化状态模型，用有限记录观察小 DC、输入阶跃和过载；检查没有用硬限幅无意掩盖内部状态发散。模型参数未从电路恢复时，只研究机制趋势。再通过 PGA、SC 与 reference 模块 TB 的证据逐步替换理想边界。

阶段验收：提交一份说明“拓扑已确认项、时序缺口、模型等级、滤波/带宽定义、下一项干预”的评审。当前没有新仿真或 bitstream，所有表中实验待执行。建议第一项仍是 D02 的一条反馈链，随后 D03 单次电荷转移。
