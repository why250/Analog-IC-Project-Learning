# R06：最小 TB、结果分析与设计判断

问题：没有整芯片 TB，能否证明一次设计判断？先预测：长窗步幅正确但短窗错误，最应先改变 bit weight 还是等待时间？先读 [无 TB 方法](../no-testbench.md)，本课形成自己的实验合同。

建议三个实验按独立问题推进。E1 读取 BOOTSTRAP 预充/抬升，必要时用理想 switch/C 重建归一化电路；输出观察 Z 而非 VIN held error。E2 从一个真实 SC/CDAC 节点抽电容端点，固定状态，只切一支路，证明符号/比例。E3 模型恢复后用真实比较器输入、bias 与交替差分检验判决/锁存时刻。每个实验另建副本，不改源库。

| 实验 | 应保存的最小证据 | 预期失败条件 |
| --- | --- | --- |
| 升压 | 原图/端点表、control vector、C 两端与 Z 曲线、负载 | 未预充/过载时抬升不足；记录机制而非芯片失败 |
| SC/CDAC 一步 | 状态前后矩阵、长短窗输出与共模、reference charge | 端点切错会反号；桥接遗漏会错比例 |
| 比较/锁存 | 前周期与当周期差分、原始动态节点、Q/QS、测量窗口 | 连续同号掩盖旧值；小 overdrive 可能超时 |

误差归因顺序：先核对 topology 与控制，再核对 DC/周期工作状态；长窗和短窗对照区分比例与建立；随后一次只改变 reference impedance、负载、clock 或输入共模。增益、offset、动态建立、noise、失配和寄生要分别有实验，不能将一次仿真残差全部称 noise。

实验阈值由目标边界定义。例如内部节点的 allowed error 必须经后级实际增益/编码传递到外部 LSB，不能直接把外部满量程/65536 套到任意比较器输入。初期没有系统 budget 时采用归一化误差，并明确它不是商业规格。

阶段评审：写出“我确认了什么、它来自哪张图/哪次运行、哪个边界仍由理想源代替、下一次什么干预能反驳我的判断”。完成一个模块不会自动闭合数字控制与整芯片输出；两路 Q<5:0> 和五路比较输出的合成仍需专课追踪。
